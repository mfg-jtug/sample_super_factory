# SampleSuperFactory - 製造データセット

## 概要
SampleSuperFactoryは、カレー製品を製造する仮想工場の統合データセットです。生産計画から品質管理、製造技術データまで、製造業における主要なデータ管理領域を網羅したサンプルデータを提供します。

## プロジェクト目的
- 製造業のデータ分析・可視化の学習用データセット
- 生産管理システム開発のリファレンスデータ
- 品質管理・トレーサビリティシステムの設計検証
- データベース設計・SQL学習の実践教材

## 主要データテーブル

### 1. マスタデータ
- **商品マスタ**: 製品の基本情報（商品ID、商品名、カテゴリなど）
- **工場マスタ**: 製造拠点の情報（工場名、所在地、生産能力など）

### 2. 在庫・生産管理
- **期初在庫数**: 工場別・商品別の期初在庫数
- **生産計画_出来高_出荷実績**: 月次の生産計画、実績、出荷データ

### 3. 品質・製造技術
- **品質管理**: 製品検査データ（約40万件）
  - QRコード、ロット情報
  - 充填・シーリング工程パラメータ
  - 重量測定値、不良情報
  
- **製造技術**: 製造工程の技術データ（約3千件）
  - 1分単位の時系列データ
  - 温度、圧力、環境条件
  - 工程別パラメータ記録

## データベース設計

各テーブルのDDL（PostgreSQL互換）は、対応するMarkdown定義書に記載されています。

### 主要な外部キー関連
```
商品マスタ ←┬─ 期初在庫数
          ├─ 生産計画_出来高_出荷実績
          ├─ 品質管理
          └─ 製造技術

工場マスタ ←─ 期初在庫数
```

## 分析ユースケース例

1. **品質分析**
   - 不良率の推移分析
   - 製造ラインごとの品質比較
   - ロットトレーサビリティ

2. **工程最適化**
   - 製造パラメータと品質の相関分析
   - 環境条件（温度・湿度）の影響分析
   - 工程時間の最適化

3. **生産管理**
   - 生産計画と実績の差異分析
   - 在庫最適化シミュレーション
   - 工場間の生産配分分析
